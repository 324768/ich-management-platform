# 非物质文化遗产管理平台智能中台设计方案

## 1. 项目概述

### 1.1 项目背景
- 毕业设计项目：非物质文化遗产(ICH)管理平台
- 核心目标：通过智能技术提升非遗文化的保护、传承与展示
- 技术栈：Spring Boot + Dubbo + Vue.js + MySQL

### 1.2 智能中台定位
- 作为系统的智能核心，为各模块提供AI能力支持
- 不改变现有架构，以服务形式提供智能功能
- 重点实现2-3个核心智能功能，确保可行性

## 2. 核心功能设计

### 2.1 智能问答助手
- **功能描述**：基于大语言模型(LLM)的智能问答系统，提供准确、自然的非遗文化问答体验
- 实现方式：
  - 集成阿里云通义千问API（或其他AI平台API）
  - 支持多轮对话上下文理解
  - 实现智能缓存机制，提高响应速度
  - 内置安全过滤，确保回答内容合规

### 2.2 智能推荐
- **功能描述**：根据用户浏览历史推荐相关非遗内容
- 实现方式：
  - 基于内容的推荐算法（简单实现）
  - 使用标签匹配推荐相似内容
  - 热门内容推荐

## 3. 技术实现

### 3.1 技术选型

#### 3.1.1 AI服务选择
- **主选方案**：阿里云通义千问API
  - 优势：国内访问稳定，中文理解能力强，提供免费额度
  - 模型：qwen-turbo（性价比高，响应快）
  - 备用方案：百度文心一言（如主选服务不可用）

### 3.2 数据库设计

#### 3.2.1 非遗项目表(ich_item)
```sql
CREATE TABLE `ich_item` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `name` varchar(100) NOT NULL COMMENT '项目名称',
  `category` varchar(50) COMMENT '类别',
  `region` varchar(100) COMMENT '地区',
  `description` text COMMENT '项目描述',
  `tags` varchar(255) COMMENT '标签，多个用逗号分隔',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.2.2 问答知识库表(qa_knowledge)
```sql
CREATE TABLE `qa_knowledge` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `question` varchar(500) NOT NULL COMMENT '问题',
  `answer` text NOT NULL COMMENT '答案',
  `keywords` varchar(255) COMMENT '关键词，用于匹配',
  `category` varchar(50) COMMENT '问题类别',
  PRIMARY KEY (`id`),
  KEY `idx_keywords` (`keywords`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.2.3 用户行为表(user_behavior)
```sql
CREATE TABLE `user_behavior` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `user_id` bigint COMMENT '用户ID',
  `item_id` bigint COMMENT '项目ID',
  `behavior_type` tinyint COMMENT '行为类型：1-浏览 2-收藏 3-分享',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_user_item` (`user_id`, `item_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 4. 接口设计

### 4.1 智能问答接口
```
POST /api/ai/qa

请求参数：
{
  "question": "京剧的起源是什么？",
  "userId": 123
}

响应：
{
  "code": 200,
  "data": {
    "answer": "京剧起源于18世纪中期的北京，是在徽剧和汉剧的基础上，...",
    "relatedItems": [
      {"id": 1, "name": "京剧"},
      {"id": 2, "name": "徽剧"}
    ]
  }
}
```

## 5. 实现步骤

### 5.1 第一阶段：基础搭建（1周）
- 搭建项目基础框架
- 实现基础数据管理功能
- 设计并创建数据库表

### 5.2 第二阶段：核心功能（2周）
- 实现智能问答服务
  - 构建基础问答知识库
  - 实现关键词匹配算法
- 实现简单推荐功能
  - 基于标签的相似内容推荐
  - 热门内容推荐

### 5.3 第三阶段：优化完善（1周）
- 优化问答匹配算法
- 完善推荐策略
- 前端界面优化
- 编写项目文档

## 6. 技术难点与解决方案

### 6.1 问答匹配准确率
- **问题**：简单关键词匹配准确率低
- **解决方案**：
  - 使用同义词扩展
  - 实现简单的语义相似度计算
  - 添加用户反馈机制，持续优化知识库

### 6.2 推荐个性化
- **问题**：如何实现个性化推荐
- **解决方案**：
  - 基于用户行为数据（浏览、收藏等）
  - 结合内容标签进行推荐
  - 实现简单的协同过滤算法

## 7. 项目亮点

1. **轻量级实现**：不依赖复杂AI框架，易于理解和实现
2. **可扩展性**：模块化设计，便于后续功能扩展
3. **实用价值**：解决非遗文化传播中的实际问题
4. **技术全面**：覆盖前后端开发全流程

## 8. 后续优化方向

1. 引入NLP技术提升问答准确率
2. 实现更复杂的推荐算法
3. 增加多模态内容处理能力
4. 添加用户画像功能
