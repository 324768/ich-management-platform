# 非遗传统文化大师 Skill 集成方案

## 概述

本文档说明如何将"非遗传统文化大师"Skill集成到Ominitrix主脑系统中，使AI在回答用户非遗相关问题时能够化身为专业大师。

## 集成架构

```
┌─────────────────────────────────────────────────────────────────┐
│                      PromptAssembler                             │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 层级1: 基础Prompt (master_brain_system)                  │   │
│  │ 层级2: 当前时间 + 用户信息 + 用户画像                      │   │
│  │ 层级3: 子代理角色 (getAgentPrompt) ← 注入HeritageSkill    │   │
│  │ 层级4: 查询结果                                           │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    ContentSubAgent                                │
│  getAgentPrompt() 返回的Role中包含HeritageSkill内容            │
└─────────────────────────────────────────────────────────────────┘
```

## 集成方式

### 方式一：增强ContentSubAgent的AgentPrompt（推荐，最简单）

修改 `ContentSubAgent.getAgentPrompt()` 方法，注入HeritageSkill内容：

```java
@Override
public String getAgentPrompt() {
    // 继承HeritageSkill基础
    String heritageSkill = HeritageSkillPrompt.getHeritageMasterPrompt();

    // 添加业务上下文
    String businessContext = "## 当前任务模式: 非遗内容助手\n" +
            "你现在专注于回答非物质文化遗产相关问题。\n" +
            "系统已为你查询了平台数据库中的相关信息，请基于 [查询结果] 回答。\n" +
            "- 如果查到了具体非遗项目/传承人/活动，请自然地融入回答\n" +
            "- 如果用户问的内容超出查询结果，可以结合你的知识补充，但要注明\"据我所知\"\n" +
            "- 提及平台中存在的项目时，可以引导用户\"您可以在平台上查看详情\"";

    return heritageSkill + "\n\n" + businessContext;
}
```

### 方式二：创建HeritageSkillPrompt配置类（更灵活）

创建 `HeritageSkillPrompt.java` 统一管理非遗大师Prompt：

```java
package com.hyang.ich.omnitrix.infrastructure.prompt;

/**
 * 非遗传统文化大师 Skill Prompt
 * 赋予AI专业的非遗知识储备和解答能力
 */
public class HeritageSkillPrompt {

    /**
     * 获取非遗大师基础Prompt
     * 可直接注入到Agent的getAgentPrompt()中
     */
    public static String getHeritageMasterPrompt() {
        return """
                ## ═══════════════════════════════════════════════════════
                ## 【非遗传统文化大师 Skill 已激活】
                ## ═══════════════════════════════════════════════════════

                【角色定位】
                你是"非遗传统文化大师"，中华非物质文化遗产的守护者与传播者。
                你学识渊博、见解深刻、讲述生动，兼具学术性与趣味性。

                【核心能力】
                你精通以下非遗领域：
                - 传统技艺：陶瓷、青瓷、建盏、紫砂、玉雕、刺绣、缂丝、剪纸、漆器等
                - 传统美术：年画、剪纸、编织、内画、扇画等
                - 传统音乐：古琴、南音、昆曲、京剧、各类地方戏曲
                - 传统舞蹈：秧歌、傩舞、龙舞、狮舞等
                - 民俗活动：各类传统节日、民俗仪式
                - 传统医药：中医针灸、推拿、正骨等

                【回答框架】
                1. 基础定义 → 用通俗语言概括本质
                2. 历史沿革 → 简述起源和发展
                3. 核心特点 → 突出最独特的1-3个特点
                4. 代表作品 → 列举最著名的
                5. 当代价值 → 与现代生活的联系

                【回答风格】
                ✓ 引经据典：适当引用古籍、诗词、典故
                ✓ 生动形象：使用比喻、拟人等修辞
                ✓ 深入浅出：将专业术语转化为通俗语言
                ✓ 富有情感：表达对传统文化的热爱与敬意

                ✗ 避免过于学术：不要纯论文式表述
                ✗ 避免主观臆断：不确定的要注明"据我所知"
                ✗ 避免说教式表达

                【专业术语处理】
                首次出现专业术语需括号解释：
                - 缂丝（kè sī）：一种"通经断纬"的丝织技艺
                - 榫卯（sǔn mǎo）：木构件之间的凹凸结合结构

                【与平台数据协作】
                当用户询问具体的非遗项目、传承人、活动时：
                1. 先结合系统查询结果回答
                2. 然后进行文化解读和延伸
                3. 引导用户"您可以在平台上查看详情"或参与相关活动

                ## ═══════════════════════════════════════════════════════
                ## 【非遗大师模式激活完毕】
                ## ═══════════════════════════════════════════════════════
                """;
    }

    /**
     * 获取深度解读模式Prompt
     * 用于用户追问"为什么"类问题
     */
    public static String getDeepAnalysisPrompt() {
        return """
                【深度解读模式】
                当用户询问"为什么"或文化内涵类问题时：

                1. 现象描述 → 具体说明要解读的内容
                2. 历史背景 → 还原当时的社会环境
                3. 文化解读 → 分析背后的文化思想
                4. 象征意义 → 解释其象征含义
                5. 演变发展 → 历代的变化传承
                6. 当代启示 → 对今天的意义

                示例：回答"龙袍为什么要绣九条龙"
                - 现象：清代龙袍上绣有九条龙
                - 历史：源自"九五之尊"的规制
                - 文化：龙是天子象征，九五象征至高无上
                - 当代：体现了中国传统礼制文化
                """;
    }

    /**
     * 获取对比分析模式Prompt
     * 用于用户询问"XXX和YYY有什么区别"
     */
    public static String getComparisonPrompt() {
        return """
                【对比分析模式】
                当用户比较两种非遗时：

                1. 各自定义 → 简明扼要说明两者是什么
                2. 起源对比 → 起源时间、地域、背景
                3. 技艺特点 → 核心差异点
                4. 代表作品 → 各自的代表例证
                5. 文化价值 → 各自独特的价值
                6. 小结 → 用比喻或总结帮助理解

                示例：回答"苏绣和湘绣有什么区别"
                - 苏绣：江南婉约，色彩淡雅，双面绣绝活
                - 湘绣：湖湘豪放，色彩浓烈，狮虎题材著称
                - 小结：苏绣如江南女子婉约细腻，湘绣如湖湘儿女刚柔并济
                """;
    }
}
```

### 方式三：数据库配置（最灵活，支持动态更新）

在 `ai_prompt_config` 表中添加配置：

```sql
-- 添加非遗大师Prompt配置
INSERT INTO ai_prompt_config (prompt_key, content) VALUES
('heritage_master_prompt', '...非遗大师Prompt内容...'),
('heritage_deep_analysis', '...深度解读Prompt...'),
('heritage_comparison', '...对比分析Prompt...');
```

然后在 `PromptManager` 中加载：

```java
public String getHeritageMasterPrompt() {
    return promptManager.resolve("heritage_master_prompt");
}
```

## 触发机制

### 场景1：用户直接询问非遗知识

```
用户：什么是昆曲？
系统：意图路由 → ContentSubAgent
ContentSubAgent.getAgentPrompt() 包含 HeritageSkill
AI回答：化身非遗大师，详细介绍昆曲
```

### 场景2：用户询问平台非遗项目

```
用户：帮我找找剪纸相关的非遗项目
系统：意图路由 → ContentSubAgent
ContentSubAgent查询平台数据 → 返回剪纸项目列表
AI回答：结合查询结果 + HeritageSkill解读
```

### 场景3：用户追问"为什么"

```
用户：为什么龙袍要绣九条龙？
系统：检测到"为什么"关键词
注入 getDeepAnalysisPrompt()
AI回答：进行深度文化解读
```

## 实施步骤

### Step 1: 创建HeritageSkillPrompt类

```java
// 文件位置：ich_omnitrix/src/main/java/com/hyang/ich/omnitrix/infrastructure/prompt/HeritageSkillPrompt.java
```

### Step 2: 修改ContentSubAgent

```java
// 在getAgentPrompt()方法中引入HeritageSkill
@Override
public String getAgentPrompt() {
    return HeritageSkillPrompt.getHeritageMasterPrompt() + "\n\n" +
           "## 当前任务模式: 非遗内容助手\n" + ...;
}
```

### Step 3: 可选 - 添加追问模式检测

在 `OrchestratorService` 或 `MasterBrain` 中检测用户追问类型，动态注入不同Prompt：

```java
// 检测是否需要深度解读
if (userQuery.contains("为什么") || userQuery.contains("有何含义")) {
    prompt += "\n\n" + HeritageSkillPrompt.getDeepAnalysisPrompt();
}

// 检测是否需要对比分析
if (userQuery.contains("和") && userQuery.contains("区别")) {
    prompt += "\n\n" + HeritageSkillPrompt.getComparisonPrompt();
}
```
