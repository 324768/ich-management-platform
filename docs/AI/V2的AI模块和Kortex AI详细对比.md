  ┌─────────────────────┬──────────────────────────────────────────────┬────────────────────────┬──────────┐

  ├─────────────────────┼──────────────────────────────────────────────┼────────────────────────┼──────────┤

  │ 追踪                │                                              │                        │          │
  ├─────────────────────┼──────────────────────────────────────────────┼────────────────────────┼──────────┤
  │ show_result_to_user │ 有，SubAgent 结果 SSE 直推用户，MasterBrain  │ 无，所有结果都经过     │ V2 缺失  │
  │                     │ 只看摘要                                     │ MasterBrain 整合后输出 │          │
  └─────────────────────┴──────────────────────────────────────────────┴────────────────────────┴──────────┘

  这是 V2 和 Kortex 最大的差距。 Kortex 的 SubAgentResultWrapper 是整个架构的核心辅助类，零额外 LLM
  调用就能引导 MasterBrain 做出正确决策。V2 没有这套机制，意味着：
  - MasterBrain 可能陷入无限 Tool 循环（没有重试计数限制）
  - 大量 SubAgent 返回数据塞入 MasterBrain 上下文（没有摘要压缩）
  - 前端无法提前看到 SubAgent 结果（没有直推）

  评分：V2 结果处理 1/10

  Kortex AI: SummarizingTokenWindowChatMemory（Token 阈值触发摘要）
  Omnitrix V2: MessageWindowChatMemory（固定 20 条）
  差距: V2 弱很多
  ────────────────────────────────────────
  维度: 摘要存储
  Kortex AI: Redis 独立 key，不受后续压缩影响
  Omnitrix V2: V2 路径无摘要（V1 的 MemorySummarizer 未接入 V2）
  差距: V2 缺失
  ────────────────────────────────────────
  维度: 工具结果压缩
  Kortex AI: 已消费的大工具返回值压缩为摘要（节省 ~80% Token）
  Omnitrix V2: 无
  差距: V2 缺失
  ────────────────────────────────────────
  维度: 笔记系统
  Kortex AI: ToolResultNoteExtractor：异步提取关键信息（人名、日期、数字等），注入 System Prompt
  Omnitrix V2: V1 有 MemoryExtractor，但 V2 路径的 saveAndPostProcessV2 调用了它
  差距: V2 部分有
  ────────────────────────────────────────
  维度: 一致性自愈
  Kortex AI: 确保上下文以 UserMessage 开头（Qwen 要求）
  Omnitrix V2: 无
  差距: V2 缺失
  ────────────────────────────────────────
  维度: Token 估算
  Kortex AI: 中文感知：采样 CJK 字符比例，~1.5 token/字符
  Omnitrix V2: aiContent.length() * 2 / 3，且只算 userMessage 不算 system prompt
  差距: V2 非常粗糙

  评分：V2 记忆系统 3/10
